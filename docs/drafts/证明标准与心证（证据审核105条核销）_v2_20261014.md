# 【自撰】证明标准与心证：高度盖然性、排除合理怀疑、优势证据——证明度如何建模（定性还是数值）

一句话：**证明度在中国法里是"标准—结论"的定性判断，不是概率数；给图谱加数值会造出一个法院从不使用、却会被下游当成事实的中间层。**

## 1. 这条解决什么问题

"这个事实证明了吗？"——这是裁判里最核心的判断，也是图谱里最难落的一格。难点有三个：

- **标准不统一**：民事是"高度盖然性"，刑事是"排除合理怀疑"，特定民事事项（欺诈、胁迫、恶意串通、口头遗嘱、赠与）又升到"排除合理怀疑"。同一个 `MaterialFact` 在不同案件类型下达标线不同。
- **表述不统一**：判决书写"本院予以采信""本院不予采信""不足以证明""高度可能"，不写百分比。自动化抽取拿不到数值。
- **心证过程不可见**：法官的内心确信（free evaluation of evidence / intime conviction）几乎不在文书中留痕，只留下结论。

本条给出结论：**证明度建模以定性为主、数值为辅（仅供内部研究，不进裁判链路）**，并给出定性枚举与字段设计。这也是本条可复用性评为 B 而非 A 的原因——**定性枚举是硬的，数值方案是未定的，且中国法无统一数值实践。**

## 2. 是什么

**三档标准的对照**：

| 标准 | 英文 | 适用领域 | 中国法出处 | 大致强度（学理描述，**非法定**） |
|---|---|---|---|---|
| 高度盖然性 | high probability / high degree of probability | 民事一般事项 | 民诉法解释第 108 条 | 明显高于 50%，但不必到排除合理怀疑 |
| 排除合理怀疑 | beyond reasonable doubt | 刑事定罪；民事欺诈/胁迫/恶意串通/口头遗嘱/赠与 | 刑诉法第 55 条；民诉法解释第 109 条 | 最高档 |
| 优势证据 | preponderance of the evidence | 英美民事标准 | **中国法无明文** | >50% |

**关于"优势证据"的澄清（重要）**：中国法民事证明标准的官方表述是**"高度盖然性"**（民诉法解释第 108 条："对负有举证证明责任的当事人提供的证据，人民法院经审查并结合相关事实，确信待证事实的存在具有高度可能性的，应当认定该事实存在"）。学理上常有"高度盖然性 ≈ 优势证据"的简化说法，但**二者在中国法文本上不是同一个东西**——第 108 条用的是"高度可能性"，不是"可能性更大"。**本体里不要建 `preponderance` 枚举值作为中国法标准**，可保留作为英美法域对照值（SKOS `altLabel`）。

**心证是什么**：自由心证（freie Beweiswürdigung / free evaluation of evidence）指法律不预先规定证据的证明力，由裁判者依经验法则与逻辑规则自由判断。中国法表述见《民诉法解释》（2022 修正）第 105 条"人民法院应当按照法定程序，全面、客观地审核证据，依照法律规定，运用逻辑推理和日常生活经验法则，对证据有无证明力和证明力大小进行判断，并公开判断的理由和结果"。【已核销：法宝+辽河中院全文双源一致】它的本体位置是：**`ProofStandard` 是规范给定的达标线，`Conviction` 是裁判者对该线是否达成的认定结论。**

## 3. 提出者与年份（含中国法制度出处与现行条文）

- **排除合理怀疑**：源于英美刑事法，18–19 世纪定型；中国法由《刑事诉讼法》2012 年修正引入，现行《刑事诉讼法》（2018 年修正）第 55 条第 2 款第 3 项"综合全案证据，对所认定事实已排除合理怀疑"。
- **高度盖然性**：源于德国民事诉讼法的"高度盖然性"（*an Sicherheit grenzende Wahrscheinlichkeit*）表述；中国法由《民诉法解释》（法释〔2015〕5 号）第 108 条确立，2022 年修正沿用。
- **优势证据**：英美民事标准，preponderance of the evidence，常以"51%"作通俗描述。
- **中国法现行条文（**以现行文本为准**）**：
  - **《民诉法解释》（2022 年修正）第 108 条**：高度盖然性标准；同条含"认为待证事实真伪不明的，应当认定该事实不存在"——**真伪不明的处理，直接对应第 5 条的客观举证责任。**
  - **同解释第 109 条**：当事人对欺诈、胁迫、恶意串通事实的证明，以及对口头遗嘱或者赠与事实的证明，人民法院确信该待证事实存在的可能性能够排除合理怀疑的，应当认定该事实存在。**民事领域内的证明标准提高条款，是本条最重要的分层依据。**
  - **《刑事诉讼法》（2018 年修正）第 55 条第 2 款**：证据确实、充分应当符合——（一）定罪量刑的事实都有证据证明；（二）据以定案的证据均经法定程序查证属实；（三）综合全案证据，对所认定事实已排除合理怀疑。**三条件中（一）是覆盖面、（二）是证据能力、（三）是证明度。**
  - **《民诉法解释》第 90 条**：未能提供证据或者证据不足以证明其事实主张的，由负有举证证明责任的当事人承担不利后果。
  - **《民事诉讼证据规定》（法释〔2019〕19 号）第 90 条**：五类不能单独作为认定案件事实根据的证据——**这是证明力的法定"打折规则"，是证明度评估的输入。**

## 4. 核心结构

**两类节点**：

| 类 | 性质 | 谁定义 | 生命周期 |
|---|---|---|---|
| `ProofStandard` | 规范给定的达标线 | 法律 / 司法解释 | 随立法变动 |
| `Conviction` | 裁判者对某事实是否达标的认定 | 法院 | 随审级变动（二审可改） |

**`ProofStandard` 字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `standardId` | ID | |
| `standardLevel` | 枚举 | `beyondReasonableDoubt` / `highProbability` / `clearAndConvincing`（英美中间档，对照用）/ `preponderance`（英美，对照用）/ `primaFacie`（表见证明/初步证据） |
| `applicableDomain` | 枚举 | `civil` / `criminal` / `administrative` |
| `appliesToFactCategory` | 枚举 | `general` / `fraud` / `duress` / `maliciousCollusion` / `oralWill` / `gift` / `convictionFact`（定罪事实）/ `sentencingFact`（量刑事实） |
| `legalBasis` | → `Provision` | |
| `numericThreshold` | 数值（可选） | **仅内部研究字段**，见第 8 节 |

**`Conviction` 字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `targetFact` | → `MaterialFact` | 对哪个待证事实的心证 |
| `requiredStandard` | → `ProofStandard` | 应适用的标准 |
| `outcome` | 枚举 | `established`（已证明）/ `notEstablished`（未证明）/ `unclear`（真伪不明） |
| `evidenceSetCoverage` | 布尔 | 是否所有相关要件都有证据覆盖（刑事第 55 条第 2 款第 1 项） |
| `allEvidenceVerified` | 布尔 | 证据是否均经法定程序查证属实（刑事第 55 条第 2 款第 2 项） |
| `doubtExcluded` | 布尔 | 是否已排除合理怀疑（刑事第 55 条第 2 款第 3 项） |
| `reasoningSpan` | 文本 | 心证说理原文 |
| `establishedByCourt` | → `Court` | |
| `establishedInStage` | → `ProcedureStage` | |
| `concursWith` | → `Conviction` | 与其他裁判的一致/冲突 |

**真伪不明的三值逻辑**（这是本条的核心技术点）：

```
outcome = established   → 事实成立，进入归入（第 2 条）
outcome = notEstablished → 事实不成立，归入失败
outcome = unclear       → 真伪不明，触发第 5 条的 burdenOfPersuasion：
                           该要件视为不成立，负担方败诉
```

**本体里必须支持三值，不能简化为真/假二值。** 二值会把"真伪不明"强行归入"不成立"，丢失了"法院其实不知道"这一重要状态——而它恰恰是举证责任规则发生作用的唯一场合。

## 5. 规模与现状活跃度

- **制度稳定，工程空白。** 三档标准自 2015 年（民诉法解释）与 2012 年（刑诉法）确立后基本稳定。但**没有一个主流法律知识图谱把证明度建模为可查询的结构**——多数产品只做"证据—事实"二部图，不做达标判断。这是本条的差异化价值。
- **数值方案的国际实践**：贝叶斯/概率化证据分析的最著名实证研究是 **Kadane & Schum, *A Probabilistic Analysis of the Sacco and Vanzetti Evidence*, Wiley, 1996**，用概率网络重构了一整个历史案件的证据推理。Anderson、Twining、Schum 的《Analysis of Evidence》（2005）提供了非数值的图表法主流路径。**结论：数值方案在学术上成熟，在司法实务上没有落地。**
- **中国法实务态度**：裁判文书不写概率，最高法也未推行任何量化证明度规则。**因此中国法骨架必须走定性路线。**

## 7. 拿来能干什么（字段级 / 类级建议）

**新增类 `ProofStandard`**（SKOS 概念方案，非类层次）。理由：标准数量少且稳定，用 SKOS 便于挂 `legalBasis` 与多法域对照（`preponderance`、`clearAndConvincing` 作为英美域对照概念，用 `altLabel`）。

**新增类 `Conviction`**（心证认定节点）。理由：心证结论是"事实 × 标准 × 结论 × 说理 × 审级"的复合命题，且需跨审级并存（二审改判会新建），必须独立成节点。它与第 1 条的 `AdjudicativeFact` 互补——`AdjudicativeFact` 回答"认定了什么"，`Conviction` 回答"凭什么认定到这个程度"。

**`MaterialFact` 上新增字段**：
- `requiredStandard` → `ProofStandard`（该事实应适用的标准，由 `appliesToFactCategory` 推导）
- `hasConviction` → `Conviction`（多值，每个审级一个）

**新增关系**：
- `requiresStandard`：`MaterialFact` → `ProofStandard`
- `hasConviction`：`MaterialFact` → `Conviction`
- `triggersBurden`：`Conviction`（`outcome = unclear` 时）→ `BurdenAssignment`
- `concursWith`：复用（`Conviction` 之间）
- `acceptedBy`：复用（法院）

**刑事三条件的强制校验**（直接对刑诉法第 55 条第 2 款建模）：
`evidenceSetCoverage` ∧ `allEvidenceVerified` ∧ `doubtExcluded` = 定罪成立。三者任一为 false，则 `CrimeElement` 不得进入 `Subsumption.subsumptionOutcome = subsumed`。**这是本条最有操作价值的 schema 规则。**

**给下游图谱的三条落点**：
1. **达标检查器**：给定 `MaterialFact`，查 `requiredStandard`，比对 `Conviction.outcome`，输出"是否达标"。民事欺诈类事实自动升档到 `beyondReasonableDoubt`（第 109 条），这是自动化最容易漏掉的一步。
2. **真伪不明预警**：`outcome = unclear` 时自动调取 `BurdenAssignment.burdenOfPersuasion`，输出败诉风险方。**这是举证责任与证明标准的唯一交汇点，也是判决预测最有效的单一特征。**
3. **量刑事实分离**：承接 11 夹《四要件 vs 三阶层》"SentencingFactor 与定罪要素分离"的结论，`appliesToFactCategory` 增加 `sentencingFact` 值，量刑事实可适用低于定罪事实的证明度（学理通说，**中国法条号待核实**）。

## 8. 坑与局限

- **坑一：数值化诱惑。** 给 `Conviction` 加 `probability = 0.87` 会诱导下游做概率运算，而法院从不产生这个数。**本条明确：`numericThreshold` 与 `probabilityEstimate` 只作为内部研究字段存在，标注 `internalOnly`，禁止参与归入判断、禁止对客展示、禁止作为检索特征。** 若要保留，必须在 schema 上加可见性标记。
- **坑二：把"高度盖然性"当成"优势证据"。** 中国法文本是"高度可能性"，不是"可能性更大"。二者混用会导致民事标准被系统性调低。**枚举里不要建 `preponderance` 作为中国法取值。**
- **坑三：忽略第 109 条的升档。** 欺诈、胁迫、恶意串通、口头遗嘱、赠与五类事实用排除合理怀疑标准。自动化抽取若默认全案用高度盖然性，这五类事实的达标判断会系统性偏松。
- **坑四：真伪不明被塞进"不成立"。** 见第 4 节。二值化会丢掉举证责任的全部适用场景。
- **局限**：心证过程本身（法官怎么想的）在本体里只能存 `reasoningSpan` 文本，无法结构化。这是本体边界，不要试图用推理网络（第 7 条）替代——第 7 条建模的是**可外化的推理链**，不是心理过程。
- **局限**：`clearAndConvincing`（清晰且有说服力，英美中间档）在中国法无对应，仅作对照概念，不要派生规则。
- **局限**：本条可复用性 B——定性枚举可直接用，数值方案未定，且中国法无统一数值实践可依据。

## 9. 与其他条目的关系

- **本夹第 1 条**：`Conviction` 挂 `MaterialFact`（L2），`AdjudicativeFact`（L3）是其结论产物。
- **本夹第 2 条**：`outcome = notEstablished` / `unclear` 直接导致 `Subsumption.failureMode = factGap` 或 `valueInsufficient`。
- **本夹第 3 条**：证据规定第 90 条"不能单独定案"是证明度的法定打折规则，输入 `Conviction`。
- **本夹第 5 条**：`outcome = unclear` 是客观举证责任的唯一触发条件——本条与第 5 条通过 `triggersBurden` 关系闭合。
- **本夹第 7 条**：Wigmore 推理网络提供证据到事实的推理结构，`Conviction` 是网络顶端的达标判断。
- **本夹第 8 条**：推定、司法认知、自认是跳过 `Conviction` 的通道（免证事实不进入证明度评估）。
- **11 夹《四要件 vs 三阶层》**：定罪事实与量刑事实的证明度分离，承接其 SentencingFactor 分离结论。
