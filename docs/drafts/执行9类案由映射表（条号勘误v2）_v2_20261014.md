## 1. 这条解决什么问题

执行 9 类是五支线上最后一条只有框架、没有逐行映射的支线。本批把官方字段逐个挂到执行六要件（执行依据有效 / 可执行内容 / 可供执行财产 / 时效 / 管辖 / 无执行障碍）+ 各类特殊要件。

**执行 I2 与民事/行政 I2 的形态差异（本批定型）**：
- 民事 I2：事实与理由**逐行**→ 请求权要件
- 行政 I2：事实栏**通用骨架四行 + 个案头部** → 五要件
- 执行 I2：**结构化栏目**（当事人信息 / 执行依据 / 申请事项 / 事由）→ 六要件——强制执行申请书没有"事实与理由"栏目，"逐行"在执行领域是"逐字段位"
- 执行领域**无答辩侧**（申请书单状），"两状"框架不适用；骨架围绕程序节点（立案→查控→处置→分配→结案→救济）组织

## 2. 组件定义

**COMP-EXE-01 执行事项枚举表（新建）**：执行救济三级的"事项"枚举 90% 重合，建一张表三处复用——
- 异议 9 项：执行标的 / 执行立案 / 执行标的额 / 查扣冻财产 / 评估鉴定询价议价 / 财产处置 / 财产分配与发放 / 执行结案 / 其他
- 复议、监督 10 项 = 异议 9 项 + 惩戒措施（限制高消费 / 限制出入境 / 列入失信名单 / 罚款 / 拘留 / 其他）
- 头部字段差异：异议挂"执行案号"，复议/监督挂"原文书号 + 送达日期"（程序链指针，送达日期同时是复议/监督期限起算点）

**COMP-SEC-01 担保七连问（第四次复用）**：执行担保申请书的担保方式 / 债权种类及数额 / 担保范围 / 担保期间 / 担保财产情况，与前三次（金融借款、信用卡、融资租赁）同构。四次复用，升 L2 公共子图条件已充分。

**COMP-MAR-01 优先权主张位（执行侧实例）**：参与分配的"申请人是否有优先受偿权利（类型：质押抵押 / 建设工程价款 / 拆迁安置 / 消费者 / 其他）"是优先权主张位在执行分配顺位的实例——海事侧是实体法优先权（船舶优先权），执行侧是程序顺位优先权，共用 claimType=priority 标注，子类型不同。

## 6. 拿来能干什么

- 执行 9 类填空式办案：按字段位逐格填，每格已知挂哪个要件、谁举证
- COMP-EXE-01 一张枚举表服务三类救济文书，程序链指针（执行案号 / 原文书号+送达日期）把异议→复议→监督串成链
- **官方留白即职权审查位**：时效、期限、执行障碍在官方文本里没有字段位——这不是疏漏，是把审查留给法院端。建模时这些要件标 reviewBy=court-ex-officio，不需要当事人填
- 担保七连问第四次复用，建议下批正式升 L2 公共子图
