## 1. 这条解决什么问题

v1 台账「民诉法执行编」一节标注为「2023 修正」的条号实为 **2021 修正规制**，且「执行编整体 +7」的规律表述不成立。v2 按 2023 修正整体重推执行编，并把核销时发现的仲裁法 2025 修订位移一并核销。

### 2.5 民事诉讼法执行编（4 处引用，**全部勘误**）——v2 重写

**v1 的引用全部是 2021 修正条号却标注「2023 修正」。** 按法宝 statute-history 版本链逐条核验，2021→2023 为**统一 +4**：

| v1 引用 | 内容 | **现行（2023 修正，2024-01-01 施行）** | 版本链证据（法宝 statute-history） |
|---|---|---|---|
| 第 232 条 | 执行行为异议（书面异议，15 日审查；含对异议裁定的 10 日复议） | **第 236 条** | 2017 修正 225 → 2021 修正 232 → 2023 修正 236 |
| 第 233 条（v1 标「复议」） | **实为**上级法院执行申请（超六个月未执行） | **第 237 条** | 2017 修正 226 → 2021 修正 233 → 2023 修正 237 |
| 第 238 条（v1 标「担保」） | 执行担保 | **第 242 条** | 2017 修正 231 → 2021 修正 238 → 2023 修正 242 |
| 第 244 条 | 不予执行仲裁裁决（六情形） | **第 248 条** | 2017 修正 237 → 2021 修正 244 → 2023 修正 248 |
| 第 245 条 | 不予执行公证债权文书 | **第 249 条** | 2017 修正 238 → 2021 修正 245 → 2023 修正 249 |
| 第 246 条 | 申请执行时效二年 | **第 250 条** | 2017 修正 239 → 2021 修正 246 → 2023 修正 250 |

**v1 所标条号在 2023 修正下的真实内容（全部不是所标内容）**：232=公示催告申报；233=执行回转……不，更正——**232=公示催告期间申报权利，244=执行回转，246=检察监督**（检察监督链条：2017 修正 235 → 2021 修正 242 → 2023 修正 246）。

**v1 同段「执行 9 类资产件引用条号」行的整体重推**：

| v1 标注 | 2021 修正下真实内容 | 2023 修正现行 | 说明 |
|---|---|---|---|
| 232 异议 | 执行行为异议 ✓ | **236** | |
| 233 复议 | **上级执行申请**（非复议） | **237** | 标注错误：复议在执行异议条款（236）之内 |
| 234–236 监督 | **案外人异议/执行员/委托执行**（非监督） | **238–240** | 标注错误：检察监督为 **246**，上级法院监督为 **237** |
| 238 担保 | 执行担保 ✓ | **242** | |
| 244–245 不予执行 | 不予执行仲裁裁决/公证债权文书 ✓ | **248/249** | |
| 246 时效 | 申请执行时效 ✓ | **250** | |

**执行编范围引用**：v1 的「第 232–258 条」在任何版本下均不成立。现行执行程序编（第三编）= **第 235–269 条**（第十九章～第二十二章；涉外编自第 270 条起）。

**位移规律（v2 重写）**：
- 2017 修正 → 2021 修正：执行编 **+7**（如时效 239→246、异议 225→232）
- 2021 修正 → 2023 修正：执行编 **+4**（如 246→250、232→236）
- 2017 → 2023 合计 **+11**
- v1 的「2023 修正主要扩涉外编，执行编整体 +7」**不成立**：+7 是 2021 修正（相对 2017）的位移；2023 修正在 2021 基础上另有 +4。

### 2.6 仲裁法（1 处，**v2 新增核销**）

核销执行资产件时连带发现：

| 资产件引用 | 内容 | **现行（2025 修订，2026-03-01 施行）** | 版本链证据 |
|---|---|---|---|
| 仲裁法第 63 条 | 不予执行仲裁裁决 | **第 76 条**（+13） | 正本/2009/2017 均为第 63 条 → 2025 修订位移至第 76 条 |

注意两点：① 2025 修订第 76 条的援引对象已从「民事诉讼法第 213 条第二款」改为「**本法第 71 条第一款**」（法定事由改为自指）；② 2025 修订的**第 63 条现在是和解后反悔条款**——继续引「第 63 条（不予执行）」会指向完全无关的条文。
