## 任务

用以下骨架定义，对以下判决书做**逐层挂接**，给出每一层的节点（含类型、关系、
属性取值），并标出**任何骨架没有落点的内容**。

## 输入文件

1. `blind-test-judgment.txt` — 判决书原文（二审，4452 字，机动车交通事故责任纠纷，
   未挂接案由）
2. `skeleton-v3.5.1.md` — 现行中国法本体骨架 v3.5.1（类/关系/枚举/规则/组件）

## 要求产出的层与内容

| 层 | 要产出 |
| --- | --- |
| L1 主张层 | 本诉/反诉各自的 Claim，及其 claimType |
| L2 要件层 | 各 Claim 对应的 Element，及 I2 要素映射 |
| L3 抗辩层 | Defense 及其 defenseKind、objectionValue |
| L4 事实层 | MaterialFact / AdjudicativeFact，及 findingBasis |
| L5 证据层 | Evidence 与 EvidenceAdmissibilityFinding（注意争议 002：三性须是独立认定节点，不是 Evidence 的属性） |
| L6 程序层 | ProcedureStage 及审级关系（appealsFrom） |
| A 论证翼 | Issue / Argument / Attack / Preference |
| **判项** | 判决主文落在哪里——若骨架无落点，请明确标注「无落点」 |

## 最有价值的发现：挂不上

历史上这类盲测的最大产出是**发现骨架缺口**。建模者自己全量跑真实判决书时
暴露过「判项没有落点、缺 Judgment 类」（fix7 候选）——这种"挂不上"
才是要找的东西。**请不要为了让产出好看而强行挂接**；无落点请直接说无落点。

## 纪律

- 你的挂接结果**不直接改骨架**：按治理，发现问题走 12 夹裁决卡
- 判项是否成立需法律专业判断，本盲测只验「结构可走通、多模型可复现」，
  不验法理正确性

## 比对

产出后，由比对脚本（待写）将你与建模者、其他盲测方的结果逐字段 diff：
- 一致 → 结构成立
- 分歧但可归因（如条号位移、枚举取值理解差异）→ 登记待裁决
- 盲测方挂不上（骨架无落点）→ **最有价值的发现**，直接对应骨架缺口
