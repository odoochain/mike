## 2. 民诉法管辖与保全（2023 修正，2024-01-01 施行）

五条全部经法宝 `fatiao` 核验，条号未位移：

| 条号 | 内容 | 库里引用位置 |
|---|---|---|
| 第 34 条 | 专属管辖（不动产/港口作业/继承遗产） | 商事/知产映射表的管辖要件 |
| 第 35 条 | 协议管辖（约定与争议有实际联系地点） | 商事 5 类「有无仲裁、法院管辖约定」字段 |
| 第 103 条 | 诉中保全（裁定财产保全/责令作为或不作为） | 执行映射表「保全案号及保全措施最早到期时间」 |
| 第 104 条 | 诉前保全（情况紧急，提供担保，48 小时裁定） | 各映射表「诉前保全」字段 |
| 第 130 条 | 管辖异议（答辩期内提出，应诉答辩视为有管辖权） | 争点整理的程序争点 |

**结论**：民诉法管辖与保全条号在 2023 修正中**未位移**，库里引用这些概念的字段无需更正条号。

## 3. 仲裁法涉外编（2025 修订，2026-03-01 施行）

第七章 涉外仲裁的特别规定，16 条全部经法宝 `fatiao` 核验：

| 条号 | 内容 |
|---|---|
| 第 81 条 | 仲裁地（书面约定；裁决视为在仲裁地作出） |
| 第 82 条 | 涉外海事/自贸区临时仲裁选择 |
| 第 83 条 | 涉外仲裁裁决撤销事由（无仲裁协议/未获通知/超范围等） |
| 第 84 条 | 涉外仲裁裁决不予执行（引用第 83 条第 1 款 + 公共利益） |
| 第 85 条 | 境内裁决向外国法院申请承认和执行 |
| 第 86 条 | 境外仲裁机构在华设立业务机构 |
| 第 87 条 | 鼓励选择中国仲裁机构/仲裁地 |
| 第 88 条 | 境外裁决的承认与执行（被执行人住所地或财产所在地中院） |
| 第 89 条 | 仲裁机构定义（仲裁委员会、仲裁院等） |
| 第 90 条 | 仲裁时效（有规定从其规定，否则适用诉讼时效） |
| 第 91 条 | 仲裁规则制定 |
| 第 92 条 | 仲裁费用 |
| 第 93 条 | 劳动/农村土地承包/体育仲裁适用专门法律 |
| 第 94 条 | 国际投资仲裁 |
| 第 95 条 | 登记管理违规处理 |
| 第 96 条 | 施行日期 2026-03-01 |

**结论**：涉外编 81–96 全部现行有效，无位移。
